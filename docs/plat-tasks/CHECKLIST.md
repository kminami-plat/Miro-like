# 手動検証チェックリスト

2 つの画面を並べて行います。

- **新**: ホワイトボードの今日のボード（`/`）
- **旧**: https://pm.plat-yonezawa.com/plat-todo/

旧ページが読むキーを切り替えられない場合、A 節は新の画面とキーの中身だけで確認し、旧ページとの往復は
B 節（本番）で行います。キーの中身は次のコマンドで確認できます（読み取りのみ）:

```bash
curl -s "https://plat-kv.k-oda.workers.dev/kv/plat-todo-tasks-sandbox?t=$(date +%s)" | python3 -m json.tool | less
```

## A. サンドボックス（`PLAT_TASKS_KEY` 未設定）

- [ ] A-1 `scripts/seed_plat_sandbox.py` を実行し、表示された件数が本番の件数と一致する
- [ ] A-2 サインインするとすぐ今日のボードが開く（ボード一覧・「新しいボード」は出ない）。黄色の
      「サンドボックス: plat-todo-tasks-sandbox」が出ていて、「閲覧のみ」の案内は出ていない
- [ ] A-3 行の並びが名簿どおりで、最後に「担当なし」がある。担当者が 2 人のタスクが両方の行に出ている
- [ ] A-4 マスの **＋** で「テスト1」を入力して Enter → 次の空の付箋が開く → Esc。約 2 秒後に右上が
      「✓ 保存済み」になり、curl の結果に `"title": "テスト1"`、`"source": "ホワイトボード"` がある
- [ ] A-5 空の付箋を開いてそのまま外をクリック → curl の件数が増えていない
- [ ] A-6 「テスト1」を右の列へドラッグ → curl で `status` が変わっている。「完了」へ動かすと `done_at` が
      今日の日付、戻すと `null`
- [ ] A-7 「テスト1」を別の人の行へドラッグ → `assignees` が付け替わっている
- [ ] A-8 付箋の ⋯ から期限を昨日にする → 付箋に ⚠ と赤い期限、行見出しの「期限切れ」が 1 増える
- [ ] A-9 curl の結果で `suggestions` と、触っていないタスクの内容（`programId`、`milestoneId` など）が
      A-1 の直後と同じ
- [ ] A-10 `PLAT_KV_TOKEN` を一時的に誤った値にして再起動 → 編集すると赤い「保存できていない変更」が
      出る。値を戻して再起動 → ページを再読み込みすると、未送信だった変更が自動で送られる
- [ ] A-11 フィルター（事業領域・プロジェクト・期限切れのみ）で表示と行サマリーが絞り込まれる
- [ ] A-12 付箋をクリックして文字を書き換え Enter → curl で `title` が変わっている
- [ ] A-13 管理者で「行を編集」→ 新しい ID と名前を追加 → 行が現れ、その行に貼った付箋の `assignees` がその ID になる
- [ ] A-14 翌営業日の朝、アーカイブで前日が黄色になっていて、開くと前日の終わりの状態が閲覧専用で出る。
      今日のボードで付箋を動かしても、前日の記録は変わらない
- [ ] A-15 土日・祝日がカレンダーで「休日」になっている（例: 2026-09-21〜23）
- [ ] A-16 テストで作ったタスクを削除する

## B. 本番（`PLAT_TASKS_KEY=plat-todo-tasks`、承認後）

- [ ] B-1 新の右上が緑の「本番データ」になり、件数と内容が旧と一致する
- [ ] B-2 **新 → 旧**: 新で「【検証】新から作成」を追加し、担当者・期限を設定 → 旧を再読み込みすると
      同じ内容で表示される
- [ ] B-3 **旧 → 新**: 旧で「【検証】旧から作成」を追加 → 新のウィンドウをクリック（フォーカス）すると
      60 秒以内に表示される
- [ ] B-4 **同時編集**: 旧を開いたまま、新で B-2 のタスクを「進行中」へドラッグ → その後、旧を
      **再読み込みせずに** 別のタスクを編集して保存 → 新を再読み込みして、ドラッグした変更が残っているか確認。
      消えていた場合は旧ページが一覧を丸ごと上書きしている（DESIGN.md の「残るリスク」）ので、報告してください
- [ ] B-5 旧で AI 候補（suggestions）がある状態で新から 1 件編集 → 旧の候補が消えていない
- [ ] B-6 新で「完了」にしたタスクが、旧でも完了扱い・完了日付きで表示される
- [ ] B-7 旧でタスクを削除 → 新でそのタスクを編集しようとすると「他の人によって削除されていました」と出て、
      タスクは復活しない
- [ ] B-8 検証用に作ったタスクをどちらかで削除し、もう一方からも消えたことを確認する
